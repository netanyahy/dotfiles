# dotfiles

Мои конфиги для Hyprland на Gentoo Linux.

## Содержимое

- **hypr** — Hyprland, hyprlock, hypridle
- **waybar** — панель
- **kitty** — терминал
- **rofi** — лаунчер
- **fuzzel** — лаунчер
- **dunst** — уведомления
- **foot** — терминал

## Установка

```bash
git clone git@github.com:netanyahy/dotfiles.git
cp -r dotfiles/.config/* ~/.config/
```
